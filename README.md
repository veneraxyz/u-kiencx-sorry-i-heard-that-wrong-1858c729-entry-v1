Entry for the [Sorry, I Heard That Wrong](https://make.fun/competitions/u-kiencx-sorry-i-heard-that-wrong-1858c729) competition on make.fun.

## The entry

> Sorry — I heard 'make it warmer' as 'wake the farmer', and for three seconds I was ready to wake a farmer. It's warm now.

The funniest one-line apology a smart speaker gives its owner after mishearing them.

## Run

```sh
npx tsx main.ts
```

`main.ts` writes the single entry line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).
